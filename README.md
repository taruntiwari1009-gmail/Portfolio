# Tarun Tiwari — Data & Analytics Engineer Portfolio
A responsive professional portfolio focused on data engineering, analytics engineering, enterprise BI, workforce intelligence, governance and HR technology.

## Local run
```bash
npm install
npm run dev
`
## Production build
```bash
npm run build
npm run preview
`
Stack: React, TypeScript, Vite, Framer Motion, Lucide and custom CSS.
Review metrics and all factual claims against approved source documents before launch. Resume is not linked until a PDF is added. Case-study details are placeholders and avoid confidential client information. LinkedIn URL is a placeholder.
